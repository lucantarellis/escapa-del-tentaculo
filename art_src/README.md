# art_src: borradores de arte

Borradores, pruebas y archivos temporales de Aseprite. **No se versionan**: `.gitignore` ignora todo lo que hay acá salvo este README y `.gdignore`. Godot no escanea la carpeta (`.gdignore`).

Los `.aseprite` finales van en `assets/aseprite/<ruta>/<nombre>.aseprite` (versionados; Aseprite Wizard los importa en Godot).

## Convención

- Un `.aseprite` por asset. Las animaciones van como tags dentro del mismo archivo.
- Nombres en `snake_case`, sin acentos ni mayúsculas.
- Paleta: `assets/palette.gpl` (detalle en `assets/palette.md`).
- Reglas completas: `docs/arte/SPRITES.md`.

## Backup

Lo que queda acá solo existe en la PC de quien lo creó.
